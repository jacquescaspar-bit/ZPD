# Group replies — don't sound like a bot

Parents in the same group will see every comment you leave. If every one is:

> Hi [Name] — I can help. Message days/times… enrol link

…you look like a scraper.

**Rule:** solution first, no echoing their post, max ~4 short lines. Change the _shape_ every time.

---

## Before you type

1. Can you actually deliver? (subject, in-person area, budget) — if no, **skip**
2. Pick a **shape** you haven't used in this group recently
3. One link max (or none — “message me” only)

---

## Shapes (rotate)

| Shape            | Pattern                                                |
| ---------------- | ------------------------------------------------------ |
| **A. Offer**     | Can help → how to next-step                            |
| **B. Soft**      | Happy to help if still looking → DM                    |
| **C. Practical** | One useful tip → offer if useful                       |
| **D. Two-part**  | Note one constraint (e.g. two subjects) → availability |
| **E. Minimal**   | One line + link                                        |
| **F. No link**   | Offer only; link only if they ask                      |

Never use the same shape twice in a row in the same group.

---

## Phrase bank (mix, don't paste whole blocks)

**Openers**

- Happy to help if you're still looking.
- I can take this on if the days work.
- Possible on our side — depends on schedule.
- Yes — worth a quick check on availability.
- We might have someone free for that.

**Middles (optional, one only)**

- Prefer classroom teachers still in schools.
- In-home or Zoom depending on what works.
- Same tutor for both subjects where we can.
- We start light so you're not locked into a term blind.

**Closes**

- Message me preferred days.
- Send days/times and I'll check.
- Easiest is a quick message with availability.
- Or start here: https://zpdlearning.com/enrol?plan=trial
- Enrol link if useful: https://zpdlearning.com/enrol?plan=trial&promo=GROW50

**Don't**

- Repeat suburb / year / “not online” back at them
- Open with “Great question!” / “Thanks for sharing!”
- Dump the full ZPD model every time
- Put GROW50 on every reply
- Sound like a brochure
